# Implementation decisions

The supplied reference plan is preserved separately. It is a design reference, not an instruction to execute its training phases. No training phase has been run.

- Integration uses Transformers 5.21.0's `get_image_features` / `mm_encoder_outputs` interface, including native image ordering and M-RoPE. No installed library file is patched. The processor retains image token masks and grid metadata; generation's prefill/cache handling remains Qwen's own.
- Selector conditioning is public question + supplied context + options, encoded with Qwen's frozen token embeddings. Unlike the reference plan's instruction-inclusive span, this excludes role instructions so QA training and hint inference use a stable selector input. System prompts, answers, reference explanations, student attempts and generated hints are excluded.
- The model has two cross-attention blocks at width 512, sigmoid token gates and one shared null vector. The null is initialized from training images only and optionally trainable. A learned shared null is a limited learned content channel; gating is not a proof that the module cannot encode shortcuts.
- Before training, identity mode bypasses gating exactly, including the uninitialized null. The UI cannot silently activate random untrained gates. Trained checkpoints are explicit and verified by hash and architecture.
- Generation uses frozen Qwen with the transformed image features in place, not an additional prompt containing model-produced observations. Initial hints require one generation call. Answer checking retains the reference-assisted assessment and tentative diagnosis branches, but selector conditioning remains public only.
- All sequences retain the original image-token count/order, attention masks and positional metadata. Neither soft gates nor hard top-k replacement reduces decoder computation. `rho` is a feature-replacement budget, not a physical token budget.
- Restricted-letter CE supports the actual A-Z option count, not a hard-coded A-E maximum. Isolated and assistant-boundary tokenization is checked; a full-checkpoint model check additionally reports the first greedily generated answer token. Probability normalization is over available option letters, not the whole vocabulary.
- Original prepared data and audit manifests are immutable inputs to an additional image-disjoint selection. Identical RGB images are excluded from lower-priority splits, with test > validation > train. Repeated question templates on different images do not cause exclusion. The original UI inspection set remains available.
- Training is opt-in via `--train`; the default command is a data-only preflight. Only the selector optimizer exists. Non-reentrant gradient checkpointing allows gradients through the frozen decoder. Validation chooses a checkpoint; test is never opened by the training runner.
- Official Hub revisions are captured after loading and used for resume/checkpoint inference. Local model directories must retain the same weights. Structural checks alone do not checksum all backbone tensor files.
- Configured controls: identity/no-image, random features, text-only gating, free-transform adapter, option-shuffle ablation, null-type ablation, soft/hard selection, feature insertion/deletion and mismatched questions. LoRA/merger training and localization metrics are intentionally absent; these require extra implementation or unavailable annotations.
- B/D/E hint outputs use a new versioned run format. Old results are not copied or relabeled. Blinded packages reuse the seven-criterion rubric, with hashes connecting returned judgments to the exact hint and image. Generation never opens gold references.
- A reduction in answer loss establishes neither visual faithfulness nor improved tutoring. Gate values are reported as feature weights. The quality/faithfulness claims require held-out experiments that the user will run.

## Verification boundaries

Tests use the installed Qwen architecture at tiny random dimensions, fake generation for HTTP checks, and fixture data. They verify identity equivalence through forward and cached generation, gradient connectivity without optimizer steps, checkpoint integrity, option remapping, reference separation and UI results. Full pretrained inference, GPU memory, answer accuracy, all training runs and post-training hint quality remain unmeasured.
